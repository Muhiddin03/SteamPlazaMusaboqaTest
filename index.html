Diqqat! Test qoidalari

Test boshlangach quyidagilar taqiqlanadi:

      Kamera orqali kuzatuv

      Test davomida old kamerangiz yoqiladi va o'qituvchi sizni jonli kuzatib turadi. Qoidabuzarlik bo'lganda surat saqlanadi.

      • Yuzingiz kamerada ko'rinib tursin
      • Yorug' joyda o'tiring
      • Brauzer so'rasa — "Ruxsat berish" ni bosing

      Diqqat! Qoidabuzarlik

      Test davom etmoqda

      Sahifa qayta ochildi. Vaqt to'xtamaydi — tezroq davom eting.

      Test boshqa varaqda ochiq

      Test bir vaqtda faqat bitta varaqda ishlaydi. Bu varaqni yoping.
